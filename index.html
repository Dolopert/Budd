วิธีตั้งค่า Google Apps Script (ทำครั้งเดียว)
  1. เปิด Google Sheet ใหม่ → เมนู Extensions ▸ Apps Script
  2. ลบโค้ดเดิม แล้ววางโค้ดด้านล่างนี้ทั้งหมด
  3. กด Deploy ▸ New deployment → เลือก type เป็น Web app
  4. ตั้ง Execute as: Me และ Who has access: Anyone → Deploy
  5. คัดลอก Web app URL มาวางในช่องด้านบน → กด ทดสอบส่ง
  6. ตรวจง่ายๆ: เปิด Web app URL ในแท็บใหม่ ควรเห็น {"ok":true,"rows":...} = ใช้ได้
