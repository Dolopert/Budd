## 4. วิธีดึงข้อมูล (Extraction) — `scripts/extract_set.py`

อ่านไฟล์งบ SET (.xls เก่า / .xlsx / .xls ที่จริงเป็น xlsx) auto:
1. **ตรวจชนิดไฟล์จาก magic bytes** (PK=xlsx, D0CF=xls เก่า)
2. **ตรวจหน่วยจาก header**: บาท (÷1,000,000), พันบาท (÷1,000), ล้านบาท (÷1) → normalize เป็น **ล้านบาท**
3. **เลือกงบการเงินรวม (consolidated) งวดปัจจุบัน** เสมอ (คอลัมน์ซ้ายสุด)
4. **map ชื่อรายการ** ผ่าน `mapping/line_items.yml` (fail-loud ถ้าหา required ไม่เจอ)
5. **ตรวจ balance**: รวมสินทรัพย์ = รวมหนี้สิน + รวมส่วนของผู้ถือหุ้น

### รายการที่ดึง (หน่วยล้านบาท, งบการเงินรวม)
| ตัวแปร | รายการในงบ | จาก |
|--------|-----------|-----|
| `total_revenue` | รวมรายได้ (multi-step: รายได้หลัก + รายได้อื่น) | PL |
| `cogs` | ต้นทุนขาย = รวมต้นทุน หรือ ผลรวมต้นทุนตรงโรงแรม+อาหาร (ค่าบวก) | PL |
| `net_profit_total` | กำไรสำหรับงวด/ปี (= ส่วนแม่ + ส่วนได้เสียที่ไม่มีอำนาจควบคุม) | PL |
| `net_profit_parent` | กำไรส่วนผู้ถือหุ้นบริษัทใหญ่ | PL |
| `other_income` | รายได้อื่น | PL |
| `trade_receivables` | ลูกหนี้การค้าและลูกหนี้หมุนเวียนอื่น | BS |
| `inventory` | สินค้าคงเหลือ | BS |
| `trade_payables` | เจ้าหนี้การค้าและเจ้าหนี้หมุนเวียนอื่น | BS |
| `total_assets` / `total_equity` / `total_liabilities` | รวมสินทรัพย์ / ทุน / หนี้สิน | BS |
| `depreciation` | ค่าเสื่อมราคาและค่าตัดจำหน่าย | CF |

### กฎสำคัญ
- **งบไตรมาสใช้ตัวเลข 3 เดือน** (ไม่ใช่สะสม); ถ้ามีงบ 2 ชุดในชีตเดียว ใช้ชุดแรก
- **ไตรมาส 4 (derived)** = FY − Q1 − Q2 − Q3 (รายได้/ต้นทุน/กำไร)
- **งบดุลใช้ค่าเฉลี่ยแบบ chain**: งบไตรมาสเทียบ "ต้นปี" เสมอ จึงต้องต่อลำดับปลายไตรมาสก่อนหน้า

## 5. สูตรคำนวณ — ฐาน CFA (หลัก) `compute_group()`

**ค่าเฉลี่ยงบดุล** (chain ยอดปลายไตรมาสก่อนหน้า):
```
Q1: avg = (ต้นปี ธ.ค.ปีก่อน + มี.ค.) / 2
Q2: avg = (มี.ค. + มิ.ย.) / 2
Q3: avg = (มิ.ย. + ก.ย.) / 2
Q4: avg = (ก.ย. + ธ.ค.) / 2
```
**จำนวนวัน**: Q1=90, Q2=91, Q3=92, Q4=92 (รายปี = 365)

| ตัวชี้วัด | สูตร |
|----------|------|
| **NPM** | กำไรสุทธิ ÷ รายได้รวม |
| **ROA** | กำไรสุทธิ ÷ ค่าเฉลี่ยสินทรัพย์รวม |
| **ROE** | กำไรสุทธิ ÷ ค่าเฉลี่ยส่วนของผู้ถือหุ้น (รวม); ROE-แม่ = กำไรส่วนแม่ ÷ ค่าเฉลี่ยทุน |
| **DSO** | ค่าเฉลี่ยลูกหนี้การค้า ÷ รายได้รวม × จำนวนวัน |
| **DIO** | ค่าเฉลี่ยสินค้าคงเหลือ ÷ ต้นทุนขาย × จำนวนวัน |
| **DPO** | ค่าเฉลี่ยเจ้าหนี้การค้า ÷ ต้นทุนขาย × จำนวนวัน |
| **CCC** | DIO + DSO − DPO |
| **Gross Margin** | (รายได้ดำเนินงาน − ต้นทุนขาย) ÷ รายได้ดำเนินงาน *(รายได้ดำเนินงาน = รายได้รวม − รายได้อื่น)* |
| **D/E** | หนี้สินรวม ÷ ส่วนของผู้ถือหุ้นรวม |

> ROA/ROE รายไตรมาส = อัตราต่อไตรมาส (รายปี = ผลรวม 4 ไตรมาส หรือ กำไรทั้งปี ÷ ค่าเฉลี่ยต้นปี-ปลายปี)

## 6. สูตรคำนวณ — ฐาน SET (เทียบเว็บ) `set_ratios.py`

ต่างจาก CFA: **ยอดปลายงวด** (ไม่เฉลี่ย), **365 วัน**, **รายปี (TTM)**
| ตัวชี้วัด | สูตร |
|----------|------|
| **DSO** | ลูกหนี้การค้า(ปลายงวด) ÷ **รายได้ดำเนินงาน** × 365 |
| **DIO** | สินค้าคงเหลือ(ปลายงวด) ÷ ต้นทุนขาย × 365 |
| **DPO** | **เจ้าหนี้กว้าง**(ปลายงวด) ÷ ต้นทุนขาย × 365 |
| **CCC** | DSO + DIO − DPO |

### เทียบแหล่งภายนอก (สิ่งที่ยืนยัน/พบ)
- **NPM, ROA ตรงบริษัทรายงาน** (MINT ROA 2.8%=2.8%; DUSIT NPM −5.3% vs −5.1%) → ดึงข้อมูลถูก
- **DSO/DIO/DPO ต่างกันทุกแหล่ง** เพราะ**นิยามต่าง** (ไม่ใช่บั๊ก) — พิสูจน์แล้ว:
  - MINT DPO: บริษัท 67 (ต้นทุน+SG&A) / เรา CFA 106 / settrade 163
  - DUSIT DSO: บริษัท 21 (ลูกหนี้การค้าล้วน จากหมายเหตุ) / เรา 53.7 (ลูกหนี้หน้างบดุล รวมหมุนเวียนอื่น)
  - ยืนยัน: ใช้ลูกหนี้การค้าล้วน → DUSIT DSO 20.7≈21, MINT ~26≈27 (ตรงบริษัท)
- **การเปิดเผยไม่สม่ำเสมอ**: MINT เปิดครบ, DUSIT บางส่วน, CENTEL ไม่เปิด cash cycle
→ **สรุป: CFA (นิยามเดียว หน้างบดุล) เป็นฐานเดียวที่เทียบ 10 บริษัทได้ยุติธรรม**

## 8. โครงสร้าง repo + วิธีรัน

```
tour-finance/
├── data/raw/<TICKER>/<ปี>/{Q1,Q2,Q3,FY}_FS.<xls|xlsx>   # งบดิบ SET
├── mapping/
│   ├── line_items.yml      # alias ชื่อรายการ (แก้เมื่อเจอบริษัทใหม่)
│   └── benchmarks.csv      # ตัวเลขแหล่งภายนอก (settrade/MD&A/56-1)
├── scripts/
│   ├── extract_set.py      # ดึง + คำนวณ 7 ตัวชี้วัด (core)
│   ├── ingest.py           # รับ zip → detect → จัดเก็บ → rebuild CSV
│   ├── validate.py         # ตรวจ 6 ชุด independent
│   ├── compare.py          # เทียบกำไรรวม=แม่+น้อย + EPS
│   ├── set_ratios.py       # อัตราส่วนฐาน SET
│   └── report.py           # สร้าง ratios_report.xlsx (4 ชีต)
├── output/
│   ├── metrics_all.csv     # ผลรายไตรมาสทุกจุด (dataset หลัก)
│   └── ratios_report.xlsx  # ส่งมอบ: Summary_FY / SET_vs_CFA / External_MINT / Quarterly
└── docs/                   # methodology + สรุปนี้
```

**เก็บข้อมูลใหม่:** `python3 ingest.py <zip>` (แตก+เดาบริษัท/ปี/ไตรมาส+คำนวณอัตโนมัติ)
**ตรวจสอบ:** `python3 validate.py` แล้ว `python3 report.py`

**Library:** openpyxl, xlrd, pyyaml, pandas; อ่าน PDF ใช้ **PyMuPDF (fitz)** (pdfplumber/pypdf พังเรื่อง cryptography ในเครื่องนี้)
